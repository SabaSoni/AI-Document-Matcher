# AI Document Search — ქართული დოკუმენტების ძებნა

ატვირთე ქართული **Word (.docx)** ან **PDF** ფაილი → სისტემა ამოიღებს ტექსტს →
შეინახავს Odoo-ში → ამის შემდეგ **Search bar-ში ნებისმიერი სიტყვის აკრეფა
იპოვის ამ სიტყვას ფაილიდან ამოღებულ ტექსტში.**

---

## ⚠️ სანამ დაიწყებ — უსაფრთხოება

ჩატში გამოქვეყნებული პაროლი (`12345`) და API key უკვე „გაჟონა". აუცილებლად:
1. შეცვალე პაროლი Odoo-ში.
2. დააგენერირე **ახალი API key**: `Settings > Users > (შენი user) > Account Security > New API Key`, ძველი კი წაშალე.
3. კრედენშალები არასდროს ჩაწერო კოდში — გამოიყენე environment ცვლადები (სკრიპტი ასეა აწყობილი).

---

## რომელი ვარიანტი შენთვის?

| | **Path A — Custom მოდული** | **Path B — გარე სკრიპტი (API)** |
|---|---|---|
| მუშაობს | Odoo.sh, On-Premise (თვითჰოსტინგი) | **Odoo Online / SaaS** (`*.odoo.com`) და ნებისმიერზე |
| ტექსტის ამოღება | Odoo-ს სერვერზე, ავტომატურად | შენს კომპიუტერზე/სერვერზე |
| დაინსტალირება | მოდულის ატვირთვა Apps-ში | Python სკრიპტის გაშვება |
| AI შეჯამება | ჩაშენებული (არჩევითი) | შეიძლება დაემატოს |

**`edu-motors.odoo.com` სავარაუდოდ Odoo Online-ია → გჭირდება Path B.**
თუ Odoo.sh ან თვითჰოსტინგი გაქვს → Path A ჯობს. დამიდასტურე რომელი გაქვს და
ზუსტ ნაბიჯებს გავივლი.

## Path A — Custom მოდულის დაინსტალირება (Odoo.sh / On-Premise)

1. საქაღალდე `ai_document_search/` ჩააგდე შენს addons-ის დირექტორიაში.
2. სერვერზე დააინსტალირე საჭირო ბიბლიოთეკები:
   ```bash
   pip install pypdf python-docx
   ```
   (Odoo.sh-ზე დაამატე ისინი `requirements.txt`-ში repo-ს root-ში.)
3. Odoo-ში: `Apps > Update Apps List`, მოძებნე **"AI Document Search"** და დააჭირე Install.
4. გამოჩნდება მენიუ **"AI Documents"**. შედი, `New`, ატვირთე ფაილი — ტექსტი
   ავტომატურად ამოიღება. Search bar-ში აკრიფე სიტყვა და იპოვის.

### AI შეჯამების ჩართვა (არჩევითი)
`Settings > Technical > System Parameters`:
- `ai_document.anthropic_api_key` = შენი Anthropic API key
- `ai_document.anthropic_model` = `claude-haiku-4-5-20251001` (ან სხვა)

> ეს მოითხოვს, რომ Odoo-ს სერვერს ინტერნეტში გასვლა შეეძლოს (Odoo.sh/on-prem — კი; SaaS — არა).
> **ძებნისთვის AI საჭირო არ არის** — ის მხოლოდ შეჯამებას/საკვანძო სიტყვებს ამატებს.

## მნიშვნელოვანი ტექნიკური შენიშვნები

- **სკანერით გადაღებული PDF (სურათი)**: pypdf ვერ ამოიღებს ტექსტს — საჭიროა **OCR**.
  ქართულისთვის: `tesseract-ocr` + ქართული ენის პაკეტი (`tesseract-ocr-kat`) +
  `pytesseract` და `pdf2image`. ეს ცალკე დაყენებას მოითხოვს (SaaS-ზე შეუძლებელია).
  თუ დაგჭირდა, OCR-იან ვერსიას ცალკე დაგიწერ.
- **ძველი `.doc`** (binary) არ არის მხარდაჭერილი — გადაინახე `.docx`-ად.
- **Odoo ვერსია**: მოდულის `_name_search` და view-ები დაწერილია **Odoo 17/18**-ისთვის.
  Odoo 16-ზე პატარა კორექტირება სჭირდება (`_name_search` → `name_search` სხვა
  ხელმოწერით). Odoo 18-ზე `<tree>` შეიძლება `<list>`-ით ჩაანაცვლო. მითხარი ვერსია
  და მოვარგებ.
- ქართული ტექსტი Unicode-ია — pypdf და python-docx სწორად ამუშავებენ (თუ PDF
  ნამდვილ ტექსტს შეიცავს და არა სურათს).
