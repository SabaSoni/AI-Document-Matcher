# AI Document Search — ქართული დოკუმენტების ძებნა Odoo-ში

Odoo 18/19 მოდული, რომელიც ატვირთული ქართული **Word (.docx)** და **PDF** ფაილების
**შიგთავსს** ხდის საძიებელს. ატვირთე ფაილი → სისტემა ამოიღებს ტექსტს → შეინახავს
ჩანაწერზე → ამის შემდეგ **search bar-ში ნებისმიერი სიტყვის აკრეფა იპოვის ყველა
დოკუმენტს, რომელშიც ეს სიტყვა გვხვდება** — და არა მხოლოდ სათაურით. სურვილისამებრ,
Claude თითოეულ დოკუმენტს ამატებს მოკლე ქართულ შეჯამებას და საკვანძო სიტყვებს.

## რას აკეთებს

- **ატვირთვა**: ქართული `.docx` ან `.pdf` ფაილი *AI Document* ჩანაწერზე
  (მენიუ **AI Documents › Documents**).
- **ტექსტი ავტომატურად ამოიღება** შენახვისას: PDF გვერდები `pypdf`-ით, Word-ის
  აბზაცები *და ცხრილები* `python-docx`-ით. ქართული Unicode ტექსტი ინახება უცვლელად.
- **სრული ტექსტით ძებნა search bar-იდან.** ნაგულისხმევი საძიებო ველი ერთდროულად
  ეძებს სათაურში, ამოღებულ ტექსტში და AI საკვანძო სიტყვებში; ასევე არის
  *Text only* და *Keywords* ველები, სტატუსის ფილტრები და *Group by* სტატუსით / ფაილის ტიპით.
- **სწრაფია დიდ დოკუმენტებზეც**: ტექსტის ველს აქვს PostgreSQL trigram ინდექსი.
- **არჩევითი AI**: Anthropic API key-ის მითითების შემდეგ თითოეულ დამუშავებულ
  დოკუმენტს ემატება 2–3 წინადადებიანი **ქართული შეჯამება** და **5–12 საკვანძო სიტყვა**.
  ძებნა AI-ზე არ არის დამოკიდებული.
- **სტატუსი და ლოგი**: *Draft → Processed* (ან *Error*); *Processing Log* ჩანართი
  აჩვენებს რა მოხდა (ფაილის ტიპი, ამოღებული სიმბოლოები, გაფრთხილება სკანირებულ
  PDF-ზე, AI ნაბიჯის შედეგი). ცვლილებები ჩანს chatter-ში.
- **უფლებები**: შიდა მომხმარებლები ქმნიან, კითხულობენ და ასწორებენ დოკუმენტებს;
  წაშლა მხოლოდ ადმინისტრატორებს (Settings ჯგუფი) შეუძლიათ.

## მოთხოვნები

| | |
|---|---|
| Odoo | 18.0 ან 19.0 (Community ან Enterprise), საკუთარ სერვერზე ან Odoo.sh-ზე |
| Python | `pypdf`, `python-docx` (`requests` Odoo-ს მოყვება) |
| არჩევითი AI | [Anthropic API key](https://console.anthropic.com/) და Odoo სერვერიდან ინტერნეტში გასვლა |

Odoo Online (SaaS) custom მოდულებს არ უშვებს — საჭიროა Odoo.sh ან საკუთარი სერვერი.

## დაინსტალირება

საქაღალდეს addons დირექტორიაში უნდა ერქვას `ai_document_search`:

```bash
cd /path/to/your/custom_addons
git clone https://github.com/SabaSoni/AI-Document-Matcher.git ai_document_search
pip install -r ai_document_search/requirements.txt
```

Odoo.sh-ზე `pypdf` და `python-docx` ჩაწერე repo-ს root-ში მდებარე `requirements.txt`-ში.
Windows ინსტალერზე გამოიყენე Odoo-ს საკუთარი Python:
`"C:\Program Files\Odoo 19.0.<build>\python\python.exe" -m pip install pypdf python-docx`.

შემდეგ გადატვირთე Odoo და *Apps*-ში დააჭირე **Update Apps List**, მოძებნე
**AI Document Search** და დააინსტალირე. ან ტერმინალიდან:

```bash
odoo-bin -c odoo.conf -d <database> -i ai_document_search --stop-after-init
```

## გამოყენება

1. გახსენი **AI Documents › Documents** და დააჭირე **New**.
2. მიუთითე სათაური (ცარიელი დატოვების შემთხვევაში ფაილის სახელი ჩაიწერება), აირჩიე
   `.docx` ან `.pdf` ფაილი და შეინახე. ტექსტი მაშინვე ამოიღება და სტატუსი ხდება **Processed**.
3. სიაში search bar-ში აკრიფე სიტყვა და დააჭირე Enter. ნაგულისხმევი
   *Search (title + full text)* ვარიანტი იპოვის ყველა დოკუმენტს, სადაც ეს სიტყვაა.

არსებულ ჩანაწერზე ახალი ფაილის ატვირთვა ტექსტს ხელახლა ამოიღებს; ღილაკი
**Process / Re-process** იგივეს აკეთებს ხელით და შეცდომას პირდაპირ გაჩვენებს.

## არჩევითი: AI შეჯამება და საკვანძო სიტყვები

AI **ნაგულისხმევად გამორთულია**. ჩასართავად *Settings › Technical › System Parameters*
(developer mode):

| Key | მნიშვნელობა |
|---|---|
| `ai_document.anthropic_api_key` | შენი Anthropic API key |
| `ai_document.anthropic_model` | მოდელი, ნაგულისხმევად `claude-haiku-4-5-20251001` (იქმნება ინსტალაციისას) |

ამის შემდეგ ყოველ დამუშავებულ დოკუმენტს ექნება შეჯამება (*AI Summary* ჩანართი) და
საკვანძო სიტყვები (ფორმაზე, სიაში და ძებნაში). გაითვალისწინე:

- Anthropic API-ს ეგზავნება ამოღებული ტექსტის პირველი 12,000 სიმბოლო.
- AI ნაბიჯი არაფატალურია: თუ ჩავარდა (ინტერნეტი, არასწორი key, ლიმიტი), დოკუმენტი
  მაინც *Processed* და საძიებელია, მიზეზი კი *Processing Log*-ში ჩაიწერება.
- key-ის მითითებამდე დამუშავებული დოკუმენტები **Process / Re-process**-ით გამდიდრდება.

## შეზღუდვები

- **სკანირებული PDF** (გვერდების სურათები) ტექსტის ფენას არ შეიცავს — ვერაფერი ამოიღება;
  *Processing Log* ამაზე გააფრთხილებს. OCR (`tesseract` ქართული `kat` პაკეტით,
  `pytesseract`, `pdf2image`) ცალკე დამატებაა.
- ძველი binary **`.doc`** ფაილები არ არის მხარდაჭერილი — გადაინახე `.docx`-ად.
- Odoo 17-ისთვის საჭიროა ორი პატარა ცვლილება: view-ებში `<list>` → `<tree>` და იმ
  ვერსიის `_name_search` ხელმოწერა.
